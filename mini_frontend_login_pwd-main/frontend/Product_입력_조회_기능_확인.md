# Product 입력·조회 기능 확인

## 1. 확인 목적

Streamlit 프론트엔드에서 제품을 입력했을 때 백엔드에 정상적으로 저장되고, 저장된 제품이 제품 조회 화면에 올바르게 표시되는지 확인한다.

## 2. 확인 전 준비

- Streamlit 앱이 정상적으로 실행되는지 확인한다.
- 백엔드 서버 주소가 다음과 같이 설정되어 있는지 확인한다.

```python
API_BASE_URL = "https://zero2-mini-project-8r38.onrender.com"
```

- Render 무료 서버가 잠들어 있었다면 첫 요청에 시간이 오래 걸릴 수 있다.
- 기존 제품과 구분할 수 있도록 새로운 테스트 데이터를 사용한다.

## 3. 테스트 데이터

다음 데이터를 기준으로 확인한다.

| 항목 | 입력값 |
|---|---:|
| 상품명 | 기능확인용 노트 |
| 가격 | 12000 |

같은 이름의 제품이 이미 있다면 상품명 뒤에 날짜나 번호를 붙인다.

예:

```text
기능확인용 노트 0729
```

## 4. Product 입력 확인

### 확인 순서

1. Streamlit 앱에서 `Product 입력` 페이지로 이동한다.
2. 상품명에 `기능확인용 노트`를 입력한다.
3. 가격에 `12000`을 입력한다.
4. 제품 등록 버튼을 누른다.

### 정상 작동 기준

- 입력 중 앱이 중단되거나 빨간색 오류 화면이 나타나지 않는다.
- 제품 등록 완료 메시지가 나타난다.
- 백엔드가 성공 상태 코드를 반환한다.
- 빈 상품명처럼 잘못된 값을 입력하면 등록되지 않고 안내 메시지가 나타난다.

### 확인 결과

- [ ] 상품명과 가격을 입력할 수 있다.
- [ ] 제품 등록 버튼이 정상적으로 작동한다.
- [ ] 등록 성공 메시지가 나타난다.
- [ ] 앱이 오류 없이 계속 실행된다.
- [ ] 빈 상품명 입력이 차단된다.

## 5. Product 조회 확인

### 확인 순서

1. `Product 조회` 페이지로 이동한다.
2. `제품조회` 버튼을 누른다.
3. 조회 결과 표에서 방금 등록한 제품을 찾는다.
4. 상품명과 가격이 입력한 내용과 같은지 확인한다.

### 예상 결과

| id | name | price |
|---:|---|---:|
| 서버에서 생성된 ID | 기능확인용 노트 | 12000 |

`id`는 서버에서 자동으로 정해질 수 있으므로 상품명과 가격을 중심으로 확인한다.

### 정상 작동 기준

- 조회 버튼을 누르면 전체 제품 목록이 표로 나타난다.
- 표에 `id`, `name`, `price` 열이 표시된다.
- 입력 단계에서 등록한 제품이 조회된다.
- 등록한 상품명과 가격이 바뀌지 않고 표시된다.
- 제품 선택 상자를 조작해도 조회 결과가 사라지지 않는다.

### 확인 결과

- [ ] 제품조회 버튼이 정상적으로 작동한다.
- [ ] 제품 목록이 표로 표시된다.
- [ ] `id`, `name`, `price` 열이 표시된다.
- [ ] 새로 입력한 제품을 찾을 수 있다.
- [ ] 상품명이 입력값과 일치한다.
- [ ] 가격이 입력값과 일치한다.
- [ ] 화면이 다시 실행돼도 조회 결과가 유지된다.

## 6. 입력·조회 연동 최종 확인

다음 흐름이 모두 성공하면 Product 입력과 조회 기능이 정상적으로 연결된 것이다.

```text
상품명·가격 입력
→ 프론트엔드에서 등록 요청 전송
→ 백엔드에서 제품 저장
→ 전체 제품 조회 요청
→ 등록한 제품이 표에 표시
```

### 최종 판정

- [ ] 입력 기능 정상
- [ ] 조회 기능 정상
- [ ] 입력한 데이터와 조회된 데이터 일치
- [ ] 프론트엔드와 백엔드 연동 정상

## 7. 오류 상황 추가 확인

가능하다면 다음 상황도 확인한다.

| 확인 상황 | 예상 결과 |
|---|---|
| 상품명을 입력하지 않고 등록 | 상품명 입력 안내 표시 |
| 서버 응답이 15초를 초과함 | 시간 초과 안내 표시 |
| 백엔드 서버에 연결할 수 없음 | 서버 연결 실패 안내 표시 |
| 조회된 제품이 없음 | `등록된 제품이 없습니다.` 표시 |
| 서버가 정상 상태 코드가 아닌 값을 반환함 | 실패 상태 코드 안내 표시 |
